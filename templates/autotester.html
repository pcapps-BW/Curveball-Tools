Autotester

Traces a T1 end to end (1250 → 1800 → MUX → GSX), pulls PMs at each hop, and flags faults.

Forward (1250 → GSX)

Start at a 1250 DS1 and walk outward: 1250 → 1800 → MUX → GSX. Resolves the MUSE, OC sub-channel, SONET leg, ACR/CEM and T3 controller on the way. Use it when a customer DS1 is all you have.
Only works when this server is running on your own machine -- it opens the file on whichever machine runs app.py, not on the browser. Fine for the local POC; turn this off once the site is running on a shared host.
Posts the same Findings Summary + Diagnostic Summary & Full T1 Route to Slack when the run finishes. Leave blank to skip, or to reuse whatever's already saved above -- enter a new URL to replace it.

Reverse (GSX → 1250)

Start at a GSX T1 and walk inward: GSX → MUX → 1800 → 1250. Resolves the T3 controller, ACR/CEM, SONET leg, OC sub-channel and MUSE on the way. Use it when a GSX alarm is all you have.
Hands the resolved 1250 + DS1 to the forward Autotester, which walks the route again from the other end — so you get the same PM and diagnostic output, plus an independent check that both directions agree on which circuit this is. Roughly doubles the runtime. Untick for route resolution only.
Only works when this server is running on your own machine -- it opens the file on whichever machine runs app.py, not on the browser. Fine for the local POC; turn this off once the site is running on a shared host.
Posts the resolved path + where the trail ended to Slack when the run finishes. Leave blank to skip, or to reuse whatever's already saved above -- enter a new URL to replace it.
