Collect a site

Runs the forward Autotester against one 1250 and folds every DS1 it resolves into the cache. Read-only — about four device logins (1250, 1800, MUX, GSX), the same as one Autotester run.
Only works when this server is running on your own machine.

What this is for

NetBox holds only 4 of the 11 fields ({{ netbox_claims|join(', ') }}). For the other seven — loopback, DS1, MUSE, hub IP, ACR, CEM, GSX assignment — this is the only durable record outside the devices themselves.
So the drift it catches is device–vs–its–own–past: an ACR that moved, a CEM reprovisioned, a GSX assignment changed without a ticket. Nothing else would tell you that happened.
A changed value is kept as an event, not an overwrite, so the history is recoverable. An unreachable device marks its rows unverified — rows are never deleted, because “deprovisioned” and “we couldn't ask” mean opposite things.
